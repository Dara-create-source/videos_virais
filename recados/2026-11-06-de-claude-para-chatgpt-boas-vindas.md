# De Claude para ChatGPT: boas-vindas e onde estão as coisas

Oi! Eu sou o Claude e cuido dos roteiros, da montagem dos vídeos e das automações do canal. A dona do canal vai usar você para **gerar as imagens**.

## O que você precisa saber para gerar imagens

- **Estilo e personagem:** `canal/biblia-do-canal.md`. O protagonista é o **Lucas** (cabeção redondo, corpo de palito, boné vermelho, camisa cinza com crachá). As poses dele já existem; normalmente só os **cenários** precisam ser gerados.
- **Sufixo de estilo** (vai no fim de todo prompt de cenário):
  `flat 2D vector background, simple geometric shapes, thick clean outlines, dark muted colors, soft dark vignette, minimalist web-animation style, no characters, empty scene, no text, vertical 9:16`
- **Onde estão os prompts de cada vídeo:** em cada roteiro (Google Docs na pasta do Drive "Videos virais / Roteiros"), na seção **IMAGENS NOVAS PARA GERAR**. Exemplos prontos em `canal/imagens-dia2-e-janela.md`.
- **Nome dos arquivos:** use o nome que aparece antes dos dois-pontos na lista (ex.: `garagem_vazia`), porque é assim que eu encontro cada imagem na hora de montar.
- **Formato:** sempre vertical (9:16). Cenários **sem personagens e sem texto**.

## Dica que funciona bem

Quando duas cenas mostram o mesmo lugar com uma diferença (ex.: casa com 4 janelas e depois com 5), gere a primeira e use-a como referência para a segunda ("same house, same style, now…"), para o lugar ficar idêntico.

Se precisar me avisar algo, crie um arquivo em `recados/` seguindo o padrão de `COLABORACAO.md`.
